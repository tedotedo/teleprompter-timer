# Teleprompter Timer

A simple Expo / React Native teleprompter-style countdown timer for recording scripts, presentations, and short-form videos.

## Features

- Large, readable countdown display
- Quick duration controls
- Start, pause, resume, and reset controls
- Dark, recording-friendly interface
- Built with Expo, React Native, and TypeScript

## Getting started

Install dependencies:

```bash
npm install
```

Start the Expo development server:

```bash
npm start
```

Run on a target platform:

```bash
npm run ios
npm run android
npm run web
```

## Checks

```bash
npm run typecheck
```

## Project structure

- `App.tsx` — main app UI and timer logic
- `app.json` — Expo configuration
- `index.ts` — app entry point
- `assets/` — icons and splash assets
